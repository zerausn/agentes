Uploaderbot

Publica videos en TikTok

Uploaderbot es una aplicación web que permite a los creadores de contenido autenticarse con su cuenta de TikTok y publicar videos directamente a través de la Content Posting API oficial de TikTok.

Login with TikTok

Cómo funciona

  1. Inicia sesión con tu cuenta de TikTok mediante OAuth.
  2. Selecciona o arrastra un video MP4.
  3. Ajusta el título y la configuración de privacidad.
  4. Publica directamente en tu perfil de TikTok.

Productos y scopes solicitados

  • Login Kit — user.info.basic, user.info.profile, user.info.stats: identificación del usuario, nombre de avatar y estadísticas básicas.
  • Content Posting API — video.upload, video.publish: subir y publicar videos en la cuenta autenticada.
  • Share Kit — compartir enlaces desde la aplicación a TikTok.

Uso de datos

Los datos obtenidos mediante los scopes se utilizan exclusivamente para:

  • Autenticar al usuario y mostrar su perfil en la interfaz.
  • Subir y publicar videos que el usuario selecciona voluntariamente.
  • Listar videos publicados para su gestión.

Uploaderbot no almacena ni comparte datos personales con terceros. Los tokens de acceso se mantienen en memoria durante la sesión y no se persisten.
