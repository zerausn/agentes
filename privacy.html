Resumen

Uploaderbot es una aplicación web que permite a los usuarios publicar videos en TikTok mediante la Content Posting API oficial. La app utiliza OAuth para autenticar al usuario y solicita únicamente los permisos necesarios para la publicación de contenido.

Datos que procesa la app

  • Token de acceso de TikTok proporcionado por el usuario mediante OAuth.
  • Identificador único (open_id) del usuario de TikTok.
  • Información básica del perfil: nombre de usuario, avatar, estadísticas.
  • Video que el usuario selecciona y sube voluntariamente para publicar.
  • Lista de videos publicados para su gestión.

Finalidad del tratamiento

  • Autenticar al usuario mediante Login Kit de TikTok.
  • Subir y publicar videos en la cuenta de TikTok del usuario.
  • Mostrar información del perfil y videos publicados en la interfaz.

Compartición de datos

Uploaderbot no vende datos personales ni comparte información con terceros. Los datos se comparten únicamente con TikTok (ByteDance) a través de sus APIs oficiales durante la autenticación y publicación.

Conservación y seguridad

Los tokens de acceso se mantienen en memoria durante la sesión del usuario y no se almacenan de forma persistente. No se guardan videos ni datos personales en servidores propios.
