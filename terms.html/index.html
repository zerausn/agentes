Uso permitido

Uploaderbot debe usarse únicamente para publicar contenido en TikTok sobre el cual el usuario tenga los derechos necesarios.

Responsabilidad del usuario

  • Usar credenciales de TikTok válidas y obtenidas de forma legítima.
  • Cumplir las políticas de TikTok y la normativa aplicable.
  • Verificar que el contenido publicado cumple con los derechos de autor y las políticas de la plataforma.

Restricciones

  • No usar la app para contenido ilegal, engañoso o no autorizado.
  • No usar la app para evadir restricciones técnicas de TikTok.
  • No usar la app para acceso indebido o suplantación de cuentas.

Disponibilidad

La app se ofrece "tal como está", sin garantías de disponibilidad continua. Las APIs de TikTok y sus criterios de revisión pueden cambiar en cualquier momento.
